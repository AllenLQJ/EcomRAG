# UI 设计规范 · 墨与瓷

高级简约风格：暖白底、墨黑字、一条细线分层；颜色只用来区分回答来源。店铺名「栖木」为虚构名字，可替换。

设计稿（画布）：https://claude.ai/artifact/WZoWN8whLNjxbVUUXH7mVu ，含桌面对话页、手机拒答页、规范页三块。

设计稿源文件已复制到 [design/](design/)：`Main.dc.html`（桌面）、`Mobile.dc.html`（手机）、`Tokens.dc.html`（规范）、`canvas.json`（画布布局）。`.dc.html` 是设计画布的格式，需要配套的运行时才能渲染，本地直接用浏览器打开看不到效果；实现前端时把它当作带内联样式的 HTML 参考，颜色、字号、间距可直接抄。

## 颜色

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 底色 | `#F6F6F4` | 页面背景 |
| 卡片 | `#FFFFFF` | 顶栏、卡片、输入框 |
| 墨（主文字） | `#16171A` | 正文、用户气泡、强调色（默认） |
| 次要文字 | `#5C6068` | 辅助说明、时间 |
| 细线 | `#E4E4E0` | 分隔线、卡片边框 |
| 描边（加深） | `#D6D6D1` | 输入框、次要按钮边框 |
| 链接 / 引用 | `#3346C8` | 链接、FAQ 标签 |

强调色（发送按钮、引用角标）默认用墨色，可在 `#3346C8` 靛蓝、`#1F5E4E` 松绿、`#8A4B2A` 赭石之间切换。

## 组件规则

- 机器人回答不加气泡，直接排在页面上，左侧 32px 图标；用户消息用墨黑气泡，圆角 18 / 18 / 4 / 18。
- 引用来源用两列卡片：编号、标题、摘要、文件名；卡片圆角 12，白底细线边框。
- 链路 trace 为折叠区：阶段名、耗时条、毫秒数、说明；生产环境不向 C 端返回。
- 输入框圆角 20，发送按钮 44×44；快捷问题为全圆角标签，高 32。
- 触控目标不小于 44px；图标按钮需有 `aria-label`。

## 状态

- 加载中：三点脉冲动画 + 「正在查阅店铺资料…」
- 出错：赭色提示「服务有点忙，请稍后再试。」+ 重试按钮
- 限流（429）：「提问有点快，休息一分钟再问吧。」
- 拒答：「未找到答案」标签 + 说明文案 + 「联系人工客服」「换个问法」两个按钮

## 圆角与间距

- 圆角：卡片 12、输入框 20、用户气泡 18 / 4、标签与快捷问题全圆。
- 间距按 4 的倍数：组件内 8 / 12 / 16，消息之间 32，页面边距桌面 40、手机 16；内容列宽 760。
- 界面上需标注「样例数据」，页脚提示「回答由 AI 根据店铺资料生成，仅供参考」。
