# UI 设计规范 · 墨与瓷

高级简约风格：暖白底、墨黑字、一条细线分层；颜色只用来区分回答来源。店铺名「灵码」为虚构名字，可替换。

设计稿（画布）：https://claude.ai/artifact/WZoWN8whLNjxbVUUXH7mVu ，含桌面对话页、手机拒答页、规范页三块。

设计稿源文件已复制到 [design/](design/)：`Main.dc.html`（桌面）、`Mobile.dc.html`（手机）、`Tokens.dc.html`（规范）、`canvas.json`（画布布局）。`.dc.html` 是设计画布的格式，需要配套的运行时才能渲染，本地直接用浏览器打开看不到效果；实现前端时把它当作带内联样式的 HTML 参考，颜色、字号、间距可直接抄。

## 颜色

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 底色 | `#F6F6F4` | 页面背景 |
| 卡片 | `#FFFFFF` | 顶栏、卡片、输入框 |
| 墨（主文字） | `#16171A` | 正文、用户气泡、强调色（默认） |
| 次要文字 | `#5C6068` | 辅助说明、时间 |
| 细线 | `#E4E4E0` | 分隔线、卡片边框 |
| 描边（加深） | `#D6D6D1` | 输入框、次要按钮边框 |

强调色（发送按钮、引用角标）默认用墨色，可在 `#3346C8` 靛蓝、`#1F5E4E` 松绿、`#8A4B2A` 赭石之间切换。

## 字体

| 用途 | 字体与字号 |
| --- | --- |
| 标题 | Noto Serif SC，22 / 600 |
| 正文 | Noto Sans SC，16 / 500，行高 1.8 |
| 辅助 | Noto Sans SC，13–14（引用摘要 14） |
| 数据 / 引用编号 | JetBrains Mono，12 |

所有文字不小于 12px；辅助文字对比度不低于 4.5:1（引用摘要使用比次要字更深一档的颜色）。

## 组件规则

- 机器人回答不加气泡，直接排在页面上，左侧 32px 图标；用户消息用墨黑气泡，圆角 18 / 18 / 4 / 18。
- 引用来源用两列卡片（手机单列）：编号、标题、摘要，不显示文件名或文档编号；卡片圆角 12，白底细线边框。
- 回答中的引用上标 [n] 行内紧凑，不撑开行高；桌面点击区不小于 24×24 且相邻不重叠，手机提供不小于 44×44 的引用按钮。
- 链路 trace 为折叠区：阶段名、耗时条、毫秒数、说明，阶段名与字段名使用中文；默认不显示，页头的「查看链路」开关仅在演示环境（`VITE_SHOW_TRACE_TOGGLE=1`）或开发者模式（`?debug=1`）出现，开启后才请求并展示；生产环境不向 C 端返回（后端 `ALLOW_TRACE` 默认关闭）。
- 链路数值：最高分等浮点数保留两位小数，候选数与保留数保持整数，耗时四舍五入显示整数毫秒。`route` 使用上表的路由中文文案，`speculative` 显示「推测检索：是/否」；未知字段与枚举值正常展示原名、原值。
- 输入框圆角 20，发送按钮 44×44；快捷问题为全圆角标签，高 32。手机宽度下快捷问题收起为「常见问题」按钮，展开后换行排列，选中即发送并收起，不使用横向滚动；输入框占位单行显示。
- 触控目标不小于 44px；图标按钮需有 `aria-label`。

## 状态

- 加载中：三点脉冲动画 + 「正在查阅店铺资料…」
- 出错：赭色提示「服务有点忙，请稍后再试。」+ 重试按钮
- 错误气泡不展示请求编号；`request_id` 仍保留在请求结果和错误消息数据中，重试继续使用原问题与原会话。
- 限流（429）：「提问有点快，休息一分钟再问吧。」
- 拒答：「未找到答案」标签 + 说明文案 + 「联系人工客服」「换个问法」两个按钮

## 圆角与间距

- 圆角：卡片 12、输入框 20、用户气泡 18 / 4、标签与快捷问题全圆。
- 间距按 4 的倍数：组件内 8 / 12 / 16，消息之间 32，页面边距桌面 40、手机 16；内容列宽 760。
- 界面上需标注「样例数据」，页脚提示「回答由 AI 根据店铺资料生成，仅供参考」。

## 会话历史侧栏与抽屉

- 桌面视口 ≥1024px：左侧 260px 侧栏占满应用高度，保持固定；仅历史列表和聊天消息区各自滚动。侧栏与聊天区以 `line` 细线分隔。主聊天列仍为最大 760px，在剩余内容空间内居中，顶栏与输入区随内容区排布。
- 640–1023px 及手机：顶栏左侧提供 44×44px「历史」图标按钮，打开左侧 280px（最大视口 85%）抽屉；背景使用 `ink` 的低透明度遮罩。点击遮罩、关闭按钮或按 Esc 关闭；打开时焦点进入抽屉，Tab/Shift+Tab 限定在抽屉内，关闭后返回历史按钮。打开时背景不可交互、body 禁止滚动，断点变为桌面时收起抽屉。
- 侧栏/抽屉顶部为「新对话」按钮；中间按「今天 / 昨天 / 近 7 天 / 更早」分组，空分组不显示，每组按最近更新时间倒序。分组使用浏览器本地日历，近 7 天指今天及前六天，今天和昨天单独归组。
- 每项显示首问前 20 字标题及相对更新时间，长标题单行省略；标题为正文小字，时间与分组标题为 `muted` 辅助字。当前项使用 `line` 背景与 `aria-current="page"`，其余悬停使用 `card`。日期与时间不引入新的强调色。
- 删除按钮在桌面悬停、行内聚焦或按钮聚焦时显示；触控设备保持可见。删除与底部「清空全部历史」都采用行内二次确认，提供「取消」与明确的确认按钮；不可使用 window.confirm。底部常驻「历史仅保存在本浏览器」，全部配色使用现有 Tailwind 语义 token，保持墨与瓷的克制视觉。
- 导航使用 `<nav aria-label="历史对话">`，每组使用列表语义；所有按钮有可读名称、键盘操作与可见焦点，触控目标不小于 44px。空列表显示「还没有历史对话」，清空按钮禁用；新建空会话不出现在列表，首次完整回答（包括拒答）后才显示。
- 切换恢复已完成消息并滚动到底部；进行中的请求/流先中止，未完成回合丢弃。删除当前会话后切换到最近更新的其他会话，无其他会话则进入新对话空状态。历史最多 30 个会话、每个 100 条完成消息，存在版本化 localStorage 中；旧 sessionStorage 消息首次加载时迁移。禁用存储或配额不足时仍可在当前页面使用历史。
