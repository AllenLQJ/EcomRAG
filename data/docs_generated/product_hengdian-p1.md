# 灵码衡电 P1 充电宝

本文说明本商品的信息与使用要求。轻量通勤，单设备补电。
主要特点：轻量通勤，单设备补电。
包装含充电宝、说明书、C 型充电线。不包含：设备专用转接头、充电适配器。

## 参数表

| 项目 | 参数 |
| --- | --- |
| 设备类型 | 充电宝 |
| 输入要求 | 5 伏直流、3 安；9 伏直流、2 安 |
| 输出规格 | 单口最高 20 瓦；多口合计最高 15 瓦 |
| 接口配置 | C 型输入输出口 1 个，A 型输出口 1 个 |
| 尺寸 | 105 × 65 × 16 毫米 |
| 重量 | 190 克 |
| 电池容量 | 10000 毫安时，3.7 伏；额定输出容量 6000 毫安时（5 伏、2 安） |
| 协议支持 | C 型口支持 PD，A 型口不提供 PD |

### 参数口径与限制

10000 毫安时为 3.7 伏电芯容量，额定输出容量 6000 毫安时限定 5 伏、2 安，不能据此承诺给手机充满的次数。C 型口支持 PD，A 型口不提供 PD；鼓包或损坏应停用。携带电池乘机须核对航司及机场要求，以航司规定为准，不承诺可带电上机或托运资格。

## 使用与口径

本款以 C 型口给自身补电，输入可用 5 伏直流、3 安或 9 伏直流、2 安；A 型口用于输出，不作为输入口。190 克机身适合单设备随身补电，单口最高 20 瓦，多口同时使用合计最高 15 瓦，连接前核对设备与线材协议。

### 保养与售后

保持接口干燥与通风，发现异常发热、鼓包或破损时停止使用。自签收起 12 个月有限保修，针对正常使用下确认的非人为功能故障。签收之日起 7 天内商品存在质量问题可申请退货，运费由店铺承担。外观类问题需提供开箱照片或视频，客服 1–2 个工作日内审核。
