# 灵码联枢 C2 双 C 口数据线

本文说明本商品的信息与使用要求。桌面远距充电，适合较高功率。
主要特点：桌面远距充电，适合较高功率。
包装含双 C 口数据线、说明书。不包含：充电适配器、显示器、耳机。

## 参数表

| 项目 | 参数 |
| --- | --- |
| 配件类型 | 数据线 |
| 连接接口 | C 型至 C 型 |
| 传输规格 | USB 2.0，最高 480 兆比特每秒，不支持视频输出 |
| 供电能力 | 最高 100 瓦（20 伏、5 安），带电子标记芯片 |
| 尺寸 | 长度 2 米 |
| 重量 | 62 克 |

### 参数口径与限制

本款传输仍是 USB 2.0 最高 480 兆比特每秒，高功率规格不能解释为高速数据或视频能力。它不支持视频输出，62 克重量也不是整套设备重量；不承诺任何 C 型电源都可提供 100 瓦。

## 使用与口径

2 米线用于桌面较远的双 C 口连接，走线时预留弯曲余量，避免从桌角拉扯。带电子标记芯片，最高 100 瓦按 20 伏、5 安使用，但两端设备仍需支持对应输出与输入档位。

## 与相关款比较

先核对接口，再区分充电、数据与视频需求，线长和最高规格需同时满足使用条件。
对照灵码联枢 C3 高速数据线（lianshu-c3）：文件传输与兼容设备视频连接。 参数：配件类型：数据线；连接接口：C 型至 C 型；传输规格：USB 3.2 Gen 2，最高 10 吉比特每秒；兼容设备可传输 4K、60 赫兹视频；供电能力：最高 100 瓦（20 伏、5 安），带电子标记芯片；尺寸：长度 0.8 米；重量：48 克。
对照灵码联枢 C1 双 C 口数据线（lianshu-c1）：日常充电，短线整洁。 参数：配件类型：数据线；连接接口：C 型至 C 型；传输规格：USB 2.0，最高 480 兆比特每秒，不支持视频输出；供电能力：最高 60 瓦（20 伏、3 安）；尺寸：长度 1 米；重量：28 克。
比较时应保持测试条件一致，不应仅因名称相近混用参数。

### 保养与售后

拔插时握住插头，避免拉扯线身，接口进液或破损时停止使用。正常使用下的功能故障适用 12 个月有限保修。签收之日起 7 天内商品存在质量问题可申请退货，运费由店铺承担。外观类问题需提供开箱照片或视频，客服 1–2 个工作日内审核。
