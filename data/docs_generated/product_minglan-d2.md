# 灵码鸣澜 D2 蓝牙音箱

本文说明本商品的信息与使用要求。客厅摆放，侧重功率余量。
主要特点：客厅摆放，侧重功率余量。
包装含音箱、充电线与说明书。不包含：充电适配器、音频线。

## 参数表

| 项目 | 参数 |
| --- | --- |
| 额定功率 | 20 瓦 |
| 音乐续航 | 10 小时 |
| 电池容量 | 4000 毫安时 |
| 充电输入 | 5 伏直流、2 安，通用 C 型接口 |
| 连接方式 | 蓝牙 5.3、3.5 毫米音频输入 |
| 整机重量 | 980 克 |
| 防护等级 | 无防水等级 |

### 参数口径与限制

没有防护等级标注，不能放在可能淋雨的窗边或用流水冲洗。额定 20 瓦不保证每间客厅都同样响亮，10 小时是在约一半音量、室温本地音乐下测得；通用 C 型口要求 5 伏直流、2 安，不把音频口当作充电口。

## 使用与口径

980 克机身适合固定客厅位置，移动时先拔掉音频与供电连接，避免线缆拖拽。20 瓦输出可通过蓝牙 5.3 或另备的 3.5 毫米音频线输入音乐，4000 毫安时电池测试续航约 10 小时。

## 与相关款比较

便携使用关注重量和续航，固定摆放关注功率与连接方式，不用功率推断所有环境的音量。
对照灵码鸣澜 R1 蓝牙音箱（minglan-r1）：长时播放，适合露台静坐。 参数：额定功率：8 瓦；音乐续航：18 小时；电池容量：4000 毫安时；充电输入：5 伏直流、2 安，通用 C 型接口；连接方式：蓝牙 5.3；整机重量：520 克；防护等级：IPX5。
对照灵码鸣澜 D1 蓝牙音箱（minglan-d1）：桌面聆听，支持有线输入。 参数：额定功率：12 瓦；音乐续航：8 小时；电池容量：2400 毫安时；充电输入：5 伏直流、2 安，通用 C 型接口；连接方式：蓝牙 5.3、3.5 毫米音频输入；整机重量：650 克；防护等级：无防水等级。
比较时应保持测试条件一致，不应仅因名称相近混用参数。

### 保养与售后

断电后用软布擦拭，充电口保持干燥，不可自行拆改电池。正常使用下的功能故障适用 12 个月有限保修。签收之日起 7 天内商品存在质量问题可申请退货，运费由店铺承担。外观类问题需提供开箱照片或视频，客服 1–2 个工作日内审核。
