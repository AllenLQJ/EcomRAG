# 灵码栖光 L5 折叠桌面台灯

本文说明本商品的信息与使用要求。折叠灯臂，便于小空间收纳。
主要特点：折叠灯臂，便于小空间收纳。
包装含灯体、安装底座、供电线及说明书。不包含：无线遥控器、供电适配器。

## 参数表

| 项目 | 参数 |
| --- | --- |
| 额定功率 | 5 瓦 |
| 输入要求 | 5 伏直流、1.5 安 |
| 色温档位 | 3000、4500 开尔文 |
| 亮度调节 | 三档 |
| 整机重量 | 310 克 |
| 供电接口 | 通用 C 型接口 |
| 电池与联网 | 无电池，不支持联网控制 |
| 补充规格 | 折叠后高度 65 毫米 |

### 参数口径与限制

5 瓦是额定功率，折叠尺寸不能当作正常照明时的摆放高度。本款依赖持续外部供电，断电不再照明，供电适配器不在包装内；仅有两档色温，不承诺适合所有人的唯一阅读光色或治疗效果。

## 使用与口径

折叠后高度为 65 毫米，收纳前先断开供电并理顺线材，展开后确认灯臂稳定再点亮。310 克整机通过通用 C 型接口接入 5 伏直流、1.5 安电源，在三档亮度与 3000、4500 开尔文中选择。

## 与相关款比较

按桌面空间选择底座、夹式或长灯头，再核对电源、色温与调光方式。
对照灵码栖光 L6 绘读桌面台灯（qiguang-l6）：高显色照明，适合手作与绘读。 参数：额定功率：10 瓦；输入要求：12 伏直流、1.5 安；色温档位：4000 开尔文；亮度调节：五档；整机重量：760 克；供电接口：圆孔直流接口；电池与联网：无电池，不支持联网控制；补充规格：显色指数 Ra 不低于 95。
对照灵码栖光 L4 宽幅桌面台灯（qiguang-l4）：宽灯头，适合宽幅阅读桌面。 参数：额定功率：12 瓦；输入要求：12 伏直流、1.5 安；色温档位：3000、4000、5000 开尔文；亮度调节：无级调光；整机重量：900 克；供电接口：圆孔直流接口；电池与联网：无电池，不支持联网控制；补充规格：灯头宽度 450 毫米。
比较时应保持测试条件一致，不应仅因名称相近混用参数。

### 保养与售后

清洁前先断开供电，用干燥软布擦拭，不可冲洗、浸泡或自行拆开电路。正常使用下的功能故障适用 12 个月有限保修。签收之日起 7 天内商品存在质量问题可申请退货，运费由店铺承担。外观类问题需提供开箱照片或视频，客服 1–2 个工作日内审核。
