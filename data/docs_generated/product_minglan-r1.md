# 灵码鸣澜 R1 蓝牙音箱

本文说明本商品的信息与使用要求。长时播放，适合露台静坐。
主要特点：长时播放，适合露台静坐。
包装含音箱、充电线与说明书。不包含：充电适配器、音频线。

## 参数表

| 项目 | 参数 |
| --- | --- |
| 额定功率 | 8 瓦 |
| 音乐续航 | 18 小时 |
| 电池容量 | 4000 毫安时 |
| 充电输入 | 5 伏直流、2 安，通用 C 型接口 |
| 连接方式 | 蓝牙 5.3 |
| 整机重量 | 520 克 |
| 防护等级 | IPX5 |

### 参数口径与限制

IPX5 不表示可浸泡或长期露天放置，雨后先检查接口干燥状态再补电。8 瓦额定功率与 18 小时音乐续航不是同一类指标，后者按室温约一半音量测试；不提供 3.5 毫米输入，也不承诺高音量下保持相同续航。

## 使用与口径

露台静坐时为 520 克机身选择平稳台面，使用蓝牙 5.3 输入音乐，避免提带牵挂其他物品。4000 毫安时电池侧重长时播放，参考续航 18 小时；出行前以 5 伏直流、2 安通用 C 型接口充电。

## 与相关款比较

便携使用关注重量和续航，固定摆放关注功率与连接方式，不用功率推断所有环境的音量。
对照灵码鸣澜 A1 蓝牙音箱（minglan-a1）：床边聆听，旋钮调节音量。 参数：额定功率：6 瓦；音乐续航：12 小时；电池容量：2200 毫安时；充电输入：5 伏直流、2 安，通用 C 型接口；连接方式：蓝牙 5.3；整机重量：380 克；防护等级：无防水等级。
对照灵码鸣澜 D2 蓝牙音箱（minglan-d2）：客厅摆放，侧重功率余量。 参数：额定功率：20 瓦；音乐续航：10 小时；电池容量：4000 毫安时；充电输入：5 伏直流、2 安，通用 C 型接口；连接方式：蓝牙 5.3、3.5 毫米音频输入；整机重量：980 克；防护等级：无防水等级。
比较时应保持测试条件一致，不应仅因名称相近混用参数。

### 保养与售后

断电后用软布擦拭，充电口保持干燥，不可自行拆改电池。正常使用下的功能故障适用 12 个月有限保修。签收之日起 7 天内商品存在质量问题可申请退货，运费由店铺承担。外观类问题需提供开箱照片或视频，客服 1–2 个工作日内审核。
