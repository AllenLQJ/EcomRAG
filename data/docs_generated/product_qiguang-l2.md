# 灵码栖光 L2 夹式桌面台灯

本文说明本商品的信息与使用要求。夹式安装，节省小书桌空间。
主要特点：夹式安装，节省小书桌空间。
包装含灯体、安装底座、供电线及说明书。不包含：无线遥控器、供电适配器。

## 参数表

| 项目 | 参数 |
| --- | --- |
| 额定功率 | 8 瓦 |
| 输入要求 | 5 伏直流、2 安 |
| 色温档位 | 3000、4000、5000 开尔文 |
| 亮度调节 | 五档 |
| 整机重量 | 520 克 |
| 供电接口 | 通用 C 型接口 |
| 电池与联网 | 无电池，不支持联网控制 |
| 补充规格 | 夹座适用桌板厚度 10–45 毫米 |

### 参数口径与限制

8 瓦是额定功率，不表示所有摆放距离均有相同照度；桌板厚度超出范围时不能勉强安装。本款断开外部供电后即停止照明，不支持联网控制，也不承诺治疗近视；包装不含供电适配器。

## 使用与口径

夹座仅用于厚度 10–45 毫米的桌板，夹牢后再摆放 520 克灯体，避免线材拉扯夹座。通过通用 C 型接口接入 5 伏直流、2 安电源，按桌面反光在五档亮度间选择，色温有 3000、4000、5000 开尔文。

按桌面空间选择底座、夹式或长灯头，再核对电源、色温与调光方式。

对照灵码栖光 L1 桌面台灯（qiguang-l1）：适合书桌阅读和普通室内照明。 参数：额定功率：6 瓦；输入要求：5 伏直流、2 安；色温档位：3000、4000、5000 开尔文；亮度调节：三档；整机重量：400 克；供电接口：通用 C 型接口；电池与联网：无电池，不支持联网控制。
比较时应保持测试条件一致，不应仅因名称相近混用参数。

### 保养与售后

清洁前先断开供电，用干燥软布擦拭，不可冲洗、浸泡或自行拆开电路。正常使用下的功能故障适用 12 个月有限保修。签收之日起 7 天内商品存在质量问题可申请退货，运费由店铺承担。外观类问题需提供开箱照片或视频，客服 1–2 个工作日内审核。
