# 灵码鸣澜 D1 蓝牙音箱

本文说明本商品的信息与使用要求。桌面聆听，支持有线输入。
主要特点：桌面聆听，支持有线输入。
包装含音箱、充电线与说明书。不包含：充电适配器、音频线。

## 参数表

| 项目 | 参数 |
| --- | --- |
| 额定功率 | 12 瓦 |
| 音乐续航 | 8 小时 |
| 电池容量 | 2400 毫安时 |
| 充电输入 | 5 伏直流、2 安，通用 C 型接口 |
| 连接方式 | 蓝牙 5.3、3.5 毫米音频输入 |
| 整机重量 | 650 克 |
| 防护等级 | 无防水等级 |

### 参数口径与限制

本款未标注防护等级，应远离水杯溢洒与潮湿桌面，不以桌面定位推断耐水能力。有线音频输入不等于供电，不能把插入音频线当作给电池补电；8 小时按室温、约一半音量播放本地音乐测试，不承诺所有音量下相同。

## 使用与口径

桌面摆放前为 650 克机身留出稳固位置，可选蓝牙 5.3 或 3.5 毫米音频输入，音频线需另备。额定功率为 12 瓦，2400 毫安时电池支持约 8 小时音乐播放，补电输入为通用 C 型 5 伏直流、2 安。

## 与相关款比较

便携使用关注重量和续航，固定摆放关注功率与连接方式，不用功率推断所有环境的音量。
对照灵码鸣澜 D2 蓝牙音箱（minglan-d2）：客厅摆放，侧重功率余量。 参数：额定功率：20 瓦；音乐续航：10 小时；电池容量：4000 毫安时；充电输入：5 伏直流、2 安，通用 C 型接口；连接方式：蓝牙 5.3、3.5 毫米音频输入；整机重量：980 克；防护等级：无防水等级。
对照灵码鸣澜 P2 蓝牙音箱（minglan-p2）：出游随听，侧重便携续航。 参数：额定功率：5 瓦；音乐续航：14 小时；电池容量：2000 毫安时；充电输入：5 伏直流、2 安，通用 C 型接口；连接方式：蓝牙 5.3；整机重量：310 克；防护等级：IPX5。
比较时应保持测试条件一致，不应仅因名称相近混用参数。

### 保养与售后

断电后用软布擦拭，充电口保持干燥，不可自行拆改电池。自签收起 12 个月有限保修，针对正常使用下确认的非人为功能故障。签收之日起 7 天内商品存在质量问题可申请退货，运费由店铺承担。外观类问题需提供开箱照片或视频，客服 1–2 个工作日内审核。
