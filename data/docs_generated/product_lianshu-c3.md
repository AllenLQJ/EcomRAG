# 灵码联枢 C3 高速数据线

本文说明本商品的信息与使用要求。文件传输与兼容设备视频连接。
主要特点：文件传输与兼容设备视频连接。
包装含高速数据线、说明书。不包含：充电适配器、显示器、耳机。

## 参数表

| 项目 | 参数 |
| --- | --- |
| 配件类型 | 数据线 |
| 连接接口 | C 型至 C 型 |
| 传输规格 | USB 3.2 Gen 2，最高 10 吉比特每秒；兼容设备可传输 4K、60 赫兹视频 |
| 供电能力 | 最高 100 瓦（20 伏、5 安），带电子标记芯片 |
| 尺寸 | 长度 0.8 米 |
| 重量 | 48 克 |

### 参数口径与限制

电子标记芯片不能替代设备本身的视频输出功能，普通仅供电接口不会因换线得到画面。48 克线材不包含适配器；数据和视频的最高表现均取决于两端能力，不承诺所有文件类型或设备都达到上限。

## 使用与口径

0.8 米高速双 C 口线连接前先确认两端均支持 USB 3.2 Gen 2，数据上限为 10 吉比特每秒。需要显示画面时，主机与显示端还需支持视频能力，规格可达 4K、60 赫兹；供电上限 100 瓦，对应 20 伏、5 安。

## 与相关款比较

先核对接口，再区分充电、数据与视频需求，线长和最高规格需同时满足使用条件。
对照灵码联枢 H1 四口扩展器（lianshu-h1）：轻薄电脑连接常用桌面外设。 参数：配件类型：扩展器；连接接口：C 型上行；A 型下行口 2 个、HDMI 口 1 个、C 型供电口 1 个；传输规格：A 型口共享最高 5 吉比特每秒；HDMI 最高 4K、30 赫兹；供电能力：C 型供电输入最高 100 瓦，向主机供电最高 85 瓦；尺寸：95 × 32 × 12 毫米；线长 15 厘米；重量：68 克。
对照灵码联枢 C2 双 C 口数据线（lianshu-c2）：桌面远距充电，适合较高功率。 参数：配件类型：数据线；连接接口：C 型至 C 型；传输规格：USB 2.0，最高 480 兆比特每秒，不支持视频输出；供电能力：最高 100 瓦（20 伏、5 安），带电子标记芯片；尺寸：长度 2 米；重量：62 克。
比较时应保持测试条件一致，不应仅因名称相近混用参数。
