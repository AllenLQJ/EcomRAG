# 灵码栖光 L4 宽幅桌面台灯

本文说明本商品的信息与使用要求。宽灯头，适合宽幅阅读桌面。
主要特点：宽灯头，适合宽幅阅读桌面。
包装含灯体、安装底座、供电线及说明书、匹配适配器。不包含：无线遥控器。

## 参数表

| 项目 | 参数 |
| --- | --- |
| 额定功率 | 12 瓦 |
| 输入要求 | 12 伏直流、1.5 安 |
| 色温档位 | 3000、4000、5000 开尔文 |
| 亮度调节 | 无级调光 |
| 整机重量 | 900 克 |
| 供电接口 | 圆孔直流接口 |
| 电池与联网 | 无电池，不支持联网控制 |
| 补充规格 | 灯头宽度 450 毫米 |

### 参数口径与限制

12 瓦额定功率与宽灯头不等于整张桌面照度一致，三个色温档 3000、4000、5000 开尔文也不能替代灯距调整。圆孔接口不能因外形能插入就任意换用其他电压的电源；本款需持续外部供电，不承诺治疗近视。

## 使用与口径

450 毫米宽灯头放置前先预留横向空间，900 克整机需有稳定支撑。使用包装内匹配适配器连接圆孔直流接口，核对 12 伏直流、1.5 安，再用无级调光调整阅读亮度。

## 与相关款比较

按桌面空间选择底座、夹式或长灯头，再核对电源、色温与调光方式。
对照灵码栖光 L5 折叠桌面台灯（qiguang-l5）：折叠灯臂，便于小空间收纳。 参数：额定功率：5 瓦；输入要求：5 伏直流、1.5 安；色温档位：3000、4500 开尔文；亮度调节：三档；整机重量：310 克；供电接口：通用 C 型接口；电池与联网：无电池，不支持联网控制；补充规格：折叠后高度 65 毫米。
对照灵码栖光 L3 充电桌面台灯（qiguang-l3）：内置电池，适合临时移位照明。 参数：额定功率：4 瓦；输入要求：5 伏直流、1 安；色温档位：2700、4000 开尔文；亮度调节：三档；整机重量：360 克；供电接口：通用 C 型接口；电池与联网：内置 2000 毫安时电池，不支持联网控制；补充规格：满电最低亮度约 10 小时，最高亮度约 3 小时。
比较时应保持测试条件一致，不应仅因名称相近混用参数。
