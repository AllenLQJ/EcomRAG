# 灵码栖光 L1 桌面台灯

本文说明本商品的信息与使用要求。栖光 L1 为有线供电桌面台灯，适合书桌阅读和普通室内照明。包装含灯体、底座、供电线及说明书，不含供电适配器。它没有内置电池，断电后不会继续照明。

## 参数表

| 项目 | 参数 |
| --- | --- |
| 额定功率 | 6 瓦 |
| 输入要求 | 5 伏直流、2 安 |
| 色温档位 | 3000、4000、5000 开尔文 |
| 亮度调节 | 三档 |
| 整机重量 | 400 克 |
| 供电接口 | 通用 C 型接口 |
| 电池与联网 | 无电池，不支持联网控制 |

### 供电与规格核对

连接前应核对供电设备的输出规格和线材状态，接口外形匹配不代表任何输出条件都符合本灯要求。包装不含适配器，也不含充电电池，不能把供电线理解为充满一次就能脱线使用。色温用于描述光线颜色倾向，亮度档位用于调节光量，两者不是同一个参数；改变色温不能替代调整灯距或房间照明。选择桌面位置时还应考虑底座稳定和线材走向，避免拉扯电线使灯体倾倒。

## 调节与使用

短按控制键可切换亮度，长按可切换色温档位，具体操作按随盒说明书执行。暖色档适合放松场景，中间色温适合一般阅读，较冷色温可按个人习惯选择。不同房间照度、桌面反光和灯距会影响感受，不承诺治疗近视或改善眼部疾病。使用时应保持通风，避免将布料覆盖灯头或把台灯放在潮湿表面。

例如，顾客发现光线刺眼时，可以先尝试合适的亮度与摆放角度，再结合房间已有照明调整，不宜把某个色温固定描述为适合所有人的唯一选择。使用中出现闪烁、异响或异常温升时，可先断电核对供电条件并保存故障表现，不应自行拆开灯头或短接线路排查。本款没有联网控制功能，不能通过安装额外软件让它获得原参数之外的远程开关能力，也不承诺提供眼部疾病治疗效果。

### 清洁与售后

清洁前先断开供电，用干燥软布擦拭，不可冲洗、浸泡或自行拆开电路。供电异常时先确认电源符合输入规格，不要反复带故障通电。签收之日起 7 天内商品存在质量问题可申请退货，运费由店铺承担。外观类问题需提供开箱照片或视频，客服 1–2 个工作日内审核。正常使用下的功能故障适用 12 个月有限保修。
