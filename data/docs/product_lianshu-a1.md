# 灵码联枢 A1 音频转接器

本文说明本商品的信息与使用要求。有线耳机连接兼容 C 型设备。
主要特点：有线耳机连接兼容 C 型设备。
包装含音频转接器、说明书。不包含：充电适配器、显示器、耳机。

## 参数表

| 项目 | 参数 |
| --- | --- |
| 配件类型 | 音频转接器 |
| 连接接口 | C 型至 3.5 毫米音频口 |
| 传输规格 | 数字音频解码最高 24 比特、96 千赫兹，不支持视频输出 |
| 供电能力 | 主机供电，不提供充电输出 |
| 尺寸 | 长度 12 厘米 |
| 重量 | 9 克 |

### 参数口径与限制

该转接器由主机供电，不提供充电输出，也不支持视频输出，不能当作分线充电配件。9 克不包含耳机，数字音频接口外形兼容不等于所有系统均可识别，不承诺音源规格超过标注解码上限。

## 使用与口径

C 型端接支持数字音频的主机，3.5 毫米端连接另备耳机；12 厘米短线避免被耳机线悬吊拉扯。解码最高 24 比特、96 千赫兹，按主机和音源能力选择，不按显示器传输需求使用。

先核对接口，再区分充电、数据与视频需求，线长和最高规格需同时满足使用条件。
