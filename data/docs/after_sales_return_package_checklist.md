# 灵码退货包装与随寄物品核对

退回前核对包装和配件，目的是让商品、问题与本次申请能够对应，也便于保护运输中的部件。本文提供打包建议；具体需要寄回哪些物品，以本次售后指引确认的清单为准。

## 先按商品清单清点已有物品

建议先摊开本次要寄回的商品及随附物品，结合原订单与商品资料逐项核对。听岚 S1 无线耳机包装含左右耳机、充电盒、三组不同尺寸耳塞、充电线及说明书，不附充电适配器；木澈 C1 保温杯含杯体、杯盖、可拆卸密封圈和说明书，不含茶漏。清点时应把“原本不附带”和“收到后暂时找不到”分开描述，避免把本来没有的物品记作遗失。上述示例用来识别原始清单，不表示每次寄修或退货都必须按同一清单寄齐。客服尚未确认寄回范围时，可先提供已找到的物品情况，询问哪些需要随寄，不自行补入与该商品无关的配件。

## 部件固定与封箱前留存建议

打包时建议让硬质部件分别固定，避免运输途中互相摩擦；耳机与充电盒、杯体与杯盖可以先核对数量及状态，再安排适合的保护方式。键行 K2 无线键盘随附无线接收器与 C 型线，体积较小的接收器建议单独说明放置位置，避免被误认为未寄回。封箱前可拍摄商品、配件和包装的对应关系，保存原有损伤部位照片，便于区分寄出前与收件后的状态。这些是材料整理与防护建议，不新增包装材质、打包收费或必须购买特定包装的要求。若原包装已无法使用，应先向客服说明现状并确认寄件安排，不以自行猜测代替本次指引。

## 配件缺失应说明而非自行定价

如果某个随附物品找不到，建议在原申请列明缺少什么、商品是否仍可对应订单，以及是否已有相关照片。不要用另一商品的配件混装来让清单看起来齐全，也不要隐去缺件情况后直接寄出。事实规则没有给出统一的缺件扣费表、包装缺失赔付或自动拒绝标准，不能在本文中据此计算扣款或保证缺件完全不影响处理。可以向客服请求确认本次应寄回的物品与后续核对方式，再按明确指引操作。售后申请编号与商品对应关系应持续保留，之后有补充说明仍沿原申请沟通，避免物品清单散落在互不关联的聊天中，导致收件时难以辨认。

## 随箱标识与运输凭证分别保存

退货审核通过后按客服提供的国内退货指引寄回，包裹内附申请编号，不放银行卡或证件原件；寄修则由客服在售后入口给出指引和地址，不自行寄往陌生地址，不使用到付。建议将随箱标识与顾客自己保存的凭证分开，寄出后仍能找到申请及单号记录。若原先遇到破损少件，应拍摄包裹全貌、面单和破损部位，保留连续开箱视频、外箱和填充物，核对分包与装箱清单，退回前先确认这些材料如何配合核查。订单详情页“申请售后”可用于查看进度，聊天咨询不等于已提交申请；打包完成同样不表示审核或验收已经通过。
