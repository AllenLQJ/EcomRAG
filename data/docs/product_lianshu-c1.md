# 灵码联枢 C1 双 C 口数据线

本文说明本商品的信息与使用要求。日常充电，短线整洁。
主要特点：日常充电，短线整洁。
包装含双 C 口数据线、说明书。不包含：充电适配器、显示器、耳机。

## 参数表

| 项目 | 参数 |
| --- | --- |
| 配件类型 | 数据线 |
| 连接接口 | C 型至 C 型 |
| 传输规格 | USB 2.0，最高 480 兆比特每秒，不支持视频输出 |
| 供电能力 | 最高 60 瓦（20 伏、3 安） |
| 尺寸 | 长度 1 米 |
| 重量 | 28 克 |

### 参数口径与限制

该线不支持视频输出，也不是独立供电设备，60 瓦需电源与受电设备共同协商。28 克为线材重量，不包含适配器；传输速率是上限，不承诺实际文件复制始终达到标注数字，避免折弯插头根部。

## 使用与口径

1 米双 C 口线适合近距离连接，按接口方向插入，额定能力最高 60 瓦，对应 20 伏、3 安。文件复制按 USB 2.0 最高 480 兆比特每秒比较，不因双 C 外形就将它接作显示器视频线。

## 与相关款比较

先核对接口，再区分充电、数据与视频需求，线长和最高规格需同时满足使用条件。
对照灵码联枢 C2 双 C 口数据线（lianshu-c2）：桌面远距充电，适合较高功率。 参数：配件类型：数据线；连接接口：C 型至 C 型；传输规格：USB 2.0，最高 480 兆比特每秒，不支持视频输出；供电能力：最高 100 瓦（20 伏、5 安），带电子标记芯片；尺寸：长度 2 米；重量：62 克。
对照灵码联枢 A1 音频转接器（lianshu-a1）：有线耳机连接兼容 C 型设备。 参数：配件类型：音频转接器；连接接口：C 型至 3.5 毫米音频口；传输规格：数字音频解码最高 24 比特、96 千赫兹，不支持视频输出；供电能力：主机供电，不提供充电输出；尺寸：长度 12 厘米；重量：9 克。
比较时应保持测试条件一致，不应仅因名称相近混用参数。
