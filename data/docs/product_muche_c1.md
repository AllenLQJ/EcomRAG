# 灵码木澈 C1 保温杯

本文说明本商品的信息与使用要求。木澈 C1 是日常饮水用保温杯，包含杯体、杯盖、可拆卸密封圈和说明书，不附赠茶漏。顾客收到后应先检查杯口、密封圈位置和外观，再按清洁说明处理后使用。

## 参数表

| 项目 | 参数 |
| --- | --- |
| 标称容量 | 450 毫升 |
| 杯体高度 | 205 毫米 |
| 空杯重量 | 280 克 |
| 内胆材料 | 食品接触用不锈钢 |
| 保温测试 | 室温 20 摄氏度、初始水温 95 摄氏度，6 小时后不低于 55 摄氏度 |
| 清洗方式 | 温水手洗，不放入洗碗机 |

### 参数使用的前提

标称容量用于规格比较，不表示装满后仍适合运输或饮用；旋紧杯盖前应留出空间并确认密封圈位置正确。空杯重量不包含饮水，也不是装箱运输重量。测试说明同时限定环境温度、起始水温和静置时间，缺少其中任何一项都不能复述为无条件的保温保证。杯体用于普通饮水，不可把有盖保温结构理解成能承受加热或封闭加压；清洗方式也应遵守手洗说明，不能擅自改成机器高温清洗。

## 容量与保温说明

450 毫升是标称容量，不建议加水到杯口，应预留空间并缓慢旋紧杯盖。保温数字是封闭静置测试口径，频繁开盖、装水较少或环境更冷都会改变实际效果。倒出热水前确认杯盖旋紧，饮用前先试温，不承诺任意室温下都能保持相同温度。杯体不适合加热、冷冻或放入微波设备。

若顾客频繁开盖喝水后感觉降温较快，应先对照静置测试的条件，不能直接以此认定保温性能不合格。检查漏水时可核对杯盖是否旋正、密封圈是否完整就位，同时避免用滚烫的水反复试验造成烫伤。需要售后核查时，可说明使用条件并提供相关照片，不能拆改杯体夹层或使用强腐蚀用品来尝试修复。清洁后让密封部位充分晾干再装回，有助于检查是否存在异物影响贴合。

### 清洁与售后

密封圈可拆下清洗并完全晾干后装回，不使用强腐蚀清洁剂。杯体制造缺陷保障期为 6 个月，密封圈正常磨损不属于永久免费更换。签收之日起 7 天内商品存在质量问题可申请退货，运费由店铺承担。外观类问题需提供开箱照片或视频，客服 1–2 个工作日内审核。人为跌落造成凹陷需要另行核查。
