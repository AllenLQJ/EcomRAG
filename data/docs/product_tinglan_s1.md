# 灵码听岚 S1 无线耳机

本文说明本商品的信息与使用要求。听岚 S1 是入耳式双耳无线耳机，定位日常通勤与语音通话。包装含左右耳机、充电盒、三组不同尺寸耳塞、充电线及说明书，不附带充电适配器。

## 参数表

| 项目 | 参数 |
| --- | --- |
| 单次音乐续航 | 8 小时 |
| 含充电盒总续航 | 32 小时 |
| 单只耳机重量 | 4.2 克 |
| 充电盒接口 | 通用 C 型接口 |
| 完整充电时间 | 耳机约 1.5 小时，盒约 2 小时 |
| 防护等级 | 耳机防泼溅，充电盒不防水 |
| 降噪能力 | 通话环境降噪，无主动降噪 |

### 参数的比较方式

选购时可把单次续航理解为耳机满电后的连续播放时间，含盒总续航则包含充电盒提供的后续补电，不是充电盒自身还能播放音乐的时长。单只重量指一侧耳机，不含充电盒，也不能据此推算整套包装的运输重量。通话环境降噪用于通话场景，不能据此判断本款具有主动降噪模式。若顾客需要主动降噪，可对照听岚 S2 的独立参数，不要仅根据两款名称相近而混用功能和续航数据。

## 使用与续航口径

8 小时和 32 小时为音量约一半、连续播放本地音乐时的测试值，通话、较大音量和低温环境会缩短续航。总续航包含耳机首次电量，不应将 8 与 32 再相加。听岚 S2 的对应数字是 10 小时与 40 小时，且 S2 另有主动降噪模式；不能把 S2 的能力套用到 S1。使用前选择合适耳塞，首次配对需从设备无线连接列表选择商品名。

比较续航时应保持测试口径一致，例如不要用一款低音量播放音乐的数字，对比另一款持续通话的实际结果。首次配对前可先确认左右耳机与充电盒电量，避免把未充足电导致的短时间使用误判为电池规格不同。实际使用出现续航异常时，应记录音量、环境温度、是否频繁通话及充电情况，再由客服协助核查；正常环境变化导致的时长差异，不应直接被当成厂家参数已经变更的结论。

### 维护与售后

耳机不适合游泳、浸泡或热水冲洗；擦干后再充电，充电盒不要接触液体。本商品不是医疗器械，不承诺改善听力。签收之日起 7 天内商品存在质量问题可申请退货，运费由店铺承担。外观类问题需提供开箱照片或视频，客服 1–2 个工作日内审核。正常使用下的功能故障适用 12 个月有限保修。
