# 入门配置：先完成补电与日常聆听

入门配置应围绕明确任务建立最短连接路径，再决定是否增加设备。以下用品分别承担电源、线材和聆听任务，组合使用仍需核对各端要求。

## 基础电源先核对受电设备需求

衡电 A1 充电器（hengdian-a1）的接口配置为“C 型输出口 1 个”；输出规格为“最高 20 瓦；5 伏、3 安或 9 伏、2.22 安”；协议支持为“C 型口支持 PD”。单口电源适合先核对常用设备的补电路径，但最高输出需与设备协商，不把不同电压电流档位相加。它不含电池，依赖交流输入，不能当作外出储电设备。包装不含线材，因此准备清单不能只写电源；若之后需要多设备同时补电，应重新按接口和合计输出选择，而不是用分线器把单口改成未声明的多口供电。

入门阶段可先把现有设备已有的能力记下来，确认缺少的是电源、线材还是个人聆听用品。最高值相近不说明它们天然组成兼容套装，每个连接端仍需要单独核对输入与输出条件。

## 基础线材明确解决什么任务

联枢 C1 双 C 口数据线（lianshu-c1）的连接接口为“C 型至 C 型”；供电能力为“最高 60 瓦（20 伏、3 安）”；传输规格为“USB 2.0，最高 480 兆比特每秒，不支持视频输出”；尺寸为“长度 1 米”。线材上限高于电源并不意味着电源会增加输出，两端设备仍要满足对应协议。基础数据能力不能当作高速复制或显示能力，不支持视频输出时不要反复接屏试错。线长应满足设备附近走线并留出插头余量，避免从桌角牵拉。配置思路是让线材完成已知任务，不是根据双 C 外形推断所有连接都能成功。

## 日常耳机先核对结构与补电配件

听岚 S1 无线耳机（tinglan-s1）的佩戴方式为“入耳式双耳无线耳机”；单只耳机重量为“4.2 克”；降噪能力为“通话环境降噪，无主动降噪”；充电盒接口为“通用 C 型接口”。先选择贴合的耳塞，再从设备无线连接列表选择商品名。耳机包装有充电线但不含充电适配器，是否采用前述电源仍以对应输入与使用要求为准，不因同属推荐组合就直接保证兼容。通话环境降噪没有主动降噪能力，不能承诺隔绝周围所有声音。耳机使用后擦干再回盒，充电盒不防水，不适合浸泡或热水冲洗。

后续需要扩展时，可按新增任务重新画连接路径，不必默认原有用品要全部替换。补电、复制文件和传输画面各有独立条件，完成前一种任务并不能证明后一种任务也已具备能力。

## 使用一段后按缺口增加配置

如果已能完成常用补电和个人聆听，后续再依据是否需要多口电源、视频线或分类收纳作选择，不能从入门名称推出自动升级路径。音乐续航有测试条件，通话、较大音量和低温会影响结果，不以含盒总时长保证持续通话。遇到明显受损或异常发热先停用，不通过拆电池和短接线路学习排查。含电商品乘机时，带电商品（充电宝、耳机等）乘机携带规定以航司和机场最新要求为准，客服不承诺。所谓入门配置仅是任务划分，不是对所有设备兼容、固定续航或出行许可的统一承诺。
