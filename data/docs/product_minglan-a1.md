# 灵码鸣澜 A1 蓝牙音箱

本文说明本商品的信息与使用要求。床边聆听，旋钮调节音量。
主要特点：床边聆听，旋钮调节音量。
包装含音箱、充电线与说明书。不包含：充电适配器、音频线。

## 参数表

| 项目 | 参数 |
| --- | --- |
| 额定功率 | 6 瓦 |
| 音乐续航 | 12 小时 |
| 电池容量 | 2200 毫安时 |
| 充电输入 | 5 伏直流、2 安，通用 C 型接口 |
| 连接方式 | 蓝牙 5.3 |
| 整机重量 | 380 克 |
| 防护等级 | 无防水等级 |

### 参数口径与限制

未标注防护等级，不适合放在水杯易倾倒或蒸汽聚集的位置。旋钮调节不能代替设备端的音量核对，12 小时仅为室温约一半音量连续本地音乐结果；本款无 3.5 毫米输入，不承诺音量较大时仍能整晚播放。

## 使用与口径

床边放置时将 380 克机身置于平整桌面，先用蓝牙 5.3 连接，再缓慢转动音量旋钮。6 瓦是额定功率，2200 毫安时电池约可播放 12 小时音乐，供电线接通用 C 型口，要求 5 伏直流、2 安。

## 与相关款比较

便携使用关注重量和续航，固定摆放关注功率与连接方式，不用功率推断所有环境的音量。
对照灵码鸣澜 P1 蓝牙音箱（minglan-p1）：口袋携带，轻量单声道。 参数：额定功率：3 瓦；音乐续航：10 小时；电池容量：1200 毫安时；充电输入：5 伏直流、2 安，通用 C 型接口；连接方式：蓝牙 5.3；整机重量：180 克；防护等级：IPX4。
对照灵码鸣澜 R1 蓝牙音箱（minglan-r1）：长时播放，适合露台静坐。 参数：额定功率：8 瓦；音乐续航：18 小时；电池容量：4000 毫安时；充电输入：5 伏直流、2 安，通用 C 型接口；连接方式：蓝牙 5.3；整机重量：520 克；防护等级：IPX5。
比较时应保持测试条件一致，不应仅因名称相近混用参数。
