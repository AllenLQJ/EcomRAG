# 灵码鸣澜 P2 蓝牙音箱

本文说明本商品的信息与使用要求。出游随听，侧重便携续航。
主要特点：出游随听，侧重便携续航。
包装含音箱、充电线与说明书。不包含：充电适配器、音频线。

## 参数表

| 项目 | 参数 |
| --- | --- |
| 额定功率 | 5 瓦 |
| 音乐续航 | 14 小时 |
| 电池容量 | 2000 毫安时 |
| 充电输入 | 5 伏直流、2 安，通用 C 型接口 |
| 连接方式 | 蓝牙 5.3 |
| 整机重量 | 310 克 |
| 防护等级 | IPX5 |

### 参数口径与限制

IPX5 不能理解成可在水中播放，潮湿接口必须晾干后再接电。5 瓦输出与 14 小时续航分别是功率和播放时间，后者按约一半音量连续本地音乐测试；本款不支持 3.5 毫米音频输入，也不承诺无限无线距离。

## 使用与口径

310 克音箱可作为出游随听款，先用蓝牙 5.3 配对，不将挂绳当作承重工具。2000 毫安时电池的音乐续航约 14 小时，连接 5 伏直流、2 安的通用 C 型电源补电后再外出。

## 与相关款比较

便携使用关注重量和续航，固定摆放关注功率与连接方式，不用功率推断所有环境的音量。
对照灵码鸣澜 D1 蓝牙音箱（minglan-d1）：桌面聆听，支持有线输入。 参数：额定功率：12 瓦；音乐续航：8 小时；电池容量：2400 毫安时；充电输入：5 伏直流、2 安，通用 C 型接口；连接方式：蓝牙 5.3、3.5 毫米音频输入；整机重量：650 克；防护等级：无防水等级。
对照灵码鸣澜 P1 蓝牙音箱（minglan-p1）：口袋携带，轻量单声道。 参数：额定功率：3 瓦；音乐续航：10 小时；电池容量：1200 毫安时；充电输入：5 伏直流、2 安，通用 C 型接口；连接方式：蓝牙 5.3；整机重量：180 克；防护等级：IPX4。
比较时应保持测试条件一致，不应仅因名称相近混用参数。

### 保养与售后

断电后用软布擦拭，充电口保持干燥，不可自行拆改电池。正常使用下的功能故障适用 12 个月有限保修。签收之日起 7 天内商品存在质量问题可申请退货，运费由店铺承担。外观类问题需提供开箱照片或视频，客服 1–2 个工作日内审核。
