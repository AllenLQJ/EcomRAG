# 灵码衡电 A3 充电器

本文说明本商品的信息与使用要求。桌面多口，兼顾轻薄电脑与手机。
主要特点：桌面多口，兼顾轻薄电脑与手机。
包装含充电器、说明书。不包含：设备专用转接头、充电线。

## 参数表

| 项目 | 参数 |
| --- | --- |
| 设备类型 | 充电器 |
| 输入要求 | 100–240 伏交流、50/60 赫兹、1.8 安 |
| 输出规格 | 单口最高 100 瓦；三口合计最高 100 瓦（65 瓦、20 瓦与 15 瓦） |
| 接口配置 | C 型输出口 2 个，A 型输出口 1 个 |
| 尺寸 | 70 × 58 × 32 毫米（不含插脚） |
| 重量 | 205 克 |
| 电池容量 | 不含电池 |
| 协议支持 | C 型口支持 PD，A 型口不提供 PD |

### 参数口径与限制

C 型口支持 PD，A 型口不提供 PD，较高输出还受另备线材能力限制。70 × 58 × 32 毫米尺寸不含插脚，205 克机身接线后应避免拉扯并保持散热通风；包装不含线材，出现异常发热或异味时停止使用，不承诺任意设备均达最高功率。

## 使用与口径

交流输入需 100–240 伏、50/60 赫兹，输入电流规格为 1.8 安；两个 C 型口与一个 A 型口接入前分别核对协议。单口最高 100 瓦，三口合计最高 100 瓦，分配为 65 瓦、20 瓦与 15 瓦，桌面设备不能简单累加各口单用上限。

### 保养与售后

保持插脚与接口干燥，清洁前断开交流电源；异常发热或破损时停止使用。正常使用下的功能故障适用 12 个月有限保修。签收之日起 7 天内商品存在质量问题可申请退货，运费由店铺承担。外观类问题需提供开箱照片或视频，客服 1–2 个工作日内审核。
