# 灵码衡电 P3 充电宝

本文说明本商品的信息与使用要求。较高输出，适合兼容的轻薄电脑。
主要特点：较高输出，适合兼容的轻薄电脑。
包装含充电宝、说明书、C 型充电线。不包含：设备专用转接头、充电适配器。

## 参数表

| 项目 | 参数 |
| --- | --- |
| 设备类型 | 充电宝 |
| 输入要求 | C 型最高 45 瓦，5–20 伏直流 |
| 输出规格 | 单口最高 65 瓦；双口合计最高 65 瓦（45 瓦与 20 瓦） |
| 接口配置 | C 型输入输出口 1 个，C 型输出口 1 个 |
| 尺寸 | 150 × 72 × 30 毫米 |
| 重量 | 420 克 |
| 电池容量 | 20000 毫安时，3.7 伏；额定输出容量 11800 毫安时（5 伏、2 安） |
| 协议支持 | C 型口支持 PD |

### 参数口径与限制

电芯容量为 3.7 伏、20000 毫安时，额定输出容量 11800 毫安时只对应 5 伏、2 安测试，不能保证电脑的完整补电次数。两口支持 PD 仍需线材与受电设备协商，不能假设包装内线材已支持所有最高档位。携带含电池设备上机以航司规定为准，不承诺通过安检或托运许可；本体鼓包应立即停用。

## 使用与口径

一个 C 型输入输出口给本体补电时最高 45 瓦、5–20 伏直流，另一个 C 型口仅作输出。单口最高 65 瓦可供支持对应 PD 协议的轻薄电脑，双口合计最高 65 瓦按 45 瓦与 20 瓦分配，420 克机身连接前先安放稳固。

### 保养与售后

保持接口干燥与通风，发现异常发热、鼓包或破损时停止使用。正常使用下的功能故障适用 12 个月有限保修。签收之日起 7 天内商品存在质量问题可申请退货，运费由店铺承担。外观类问题需提供开箱照片或视频，客服 1–2 个工作日内审核。
