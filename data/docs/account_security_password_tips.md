# 灵码演示账号密码设置与保管建议

本文只给出设置和保管演示账号密码的使用建议。用户名与密码的格式要求、连续失败锁定和忘记密码后的处理，以《灵码账号注册、登录保护与状态保持》为准，本文不复述。灵码为演示用模拟店铺，注册页提示“演示站点，请勿使用常用的真实密码”。

## 设置密码前的准备

建议先打开注册说明核对格式要求，再动手设置，减少反复试错。设置时避开生日、连续数字、键盘顺序等容易被猜到的写法，也不要直接用用户名稍作变化当密码。本文不额外规定必须包含大小写或特殊符号，也不提供可照抄的密码示例，以免把公开示例当作私人凭据。能通过注册检查并不代表密码在所有情况下都安全；规则解决的是本站输入要求，保管仍要结合自己的设备环境和使用习惯。

## 为演示体验准备专用凭据

“演示站点，请勿使用常用的真实密码”应在输入之前理解，不要把日常重要账号的密码用于试验注册是否成功。建议为演示账号准备专用密码，避免与其他用途混用，也不要把其他平台的密码当作临时占位内容提交。店铺资料不代表真实商家政策，演示体验不能作为验证常用密码是否安全的方法。

登录注册不提供第三方登录、实名认证；店铺积分会员见会员说明，与登录方式无关。因此不要因为看到熟悉的登录页面布局，就主动交出其他平台凭据或身份证明。记录登录信息时，建议妥善保管用户名与密码的对应关系，避免在多个演示用户名之间混淆。这里的建议不代表站点提供密码管理或替顾客保存可随时取回的凭据。

## 输入失败时避免持续猜测

登录没有成功时，先停下来对照页面提示，判断是用户名还是密码出了问题，再核对自己保存的记录，不要把连续尝试当作检查凭据的常规办法；锁定条件见注册说明。用户名的大小写规则不能推导为密码也同样处理，应按自己设置的内容谨慎输入。设置阶段的妥善保管，直接影响以后能否顺利登录原账号，忘记密码后的处理同样见注册说明。不要把密码发给客服代试，也不要相信陌生人付费解锁的说法。

## 使用结束后注意访问边界

建议在共享设备上结束体验后主动退出，避免他人在仍有效的登录环境里访问你的内容；登录状态的有效期见注册说明。登录后的对话内容保存在服务器，仅本人可见，用于跨设备查看历史；这项可见范围说明不能替代顾客对当前设备访问状态的注意。关闭页面不应被当成已确认退出的依据。有人自称客服索要密码时不要提供，核对方法见《灵码可疑客服信息与防诈骗核对》。专用密码、妥善保管和主动退出是使用建议，不是保证账号绝对安全的承诺。
