# 联枢 C2 与 C3：供电同档时为何连接任务不同

两款双 C 口线都带电子标记芯片，但数据、视频和线长存在明确差异。选择应先确定任务，再核对设备两端支持的能力。

## 供电字段相同不能推出所有能力相同

联枢 C2 双 C 口数据线（lianshu-c2）的供电能力为“最高 100 瓦（20 伏、5 安），带电子标记芯片”。联枢 C3 高速数据线（lianshu-c3）的供电能力为“最高 100 瓦（20 伏、5 安），带电子标记芯片”。若任务只是满足对应功率的补电，可先核对电源与受电设备是否支持，再选择适合走线的长度。电子标记芯片不能替代供电协商，电源输出不足不会因为换成同档线材而自动提高。两者都不是独立电源，不含适配器，最高供电能力也不是任何设备实际所得功率。供电比较完成后还需单独检查数据与画面任务，不能把这些项目一起打包推断。

可先把“接得上”和“完成任务”分开检查：接口外形只能说明物理连接条件，任务还需要供电协商、数据协议或视频能力。缺少哪一项就核对哪一项，不能用其他参数的上限来代替。

## 数据上限差异要连同设备条件阅读

联枢 C2 双 C 口数据线（lianshu-c2）的传输规格为“USB 2.0，最高 480 兆比特每秒，不支持视频输出”。联枢 C3 高速数据线（lianshu-c3）的传输规格为“USB 3.2 Gen 2，最高 10 吉比特每秒；兼容设备可传输 4K、60 赫兹视频”。基础线与高速线的传输规格不同，高功率不应被当成高速数据标签。需要经常复制文件时，应先核对两端设备接口能力；经过其他扩展配件时也要检查完整路径。标注速率是上限，不能保证所有文件类型或系统都达到同样实际速度。若主机仅支持较低能力，换线不能让主机接口自动升级，不根据标称差异自行计算实际传输节省时间。

## 视频任务存在明确的支持与不支持边界

基础线明确不支持视频输出，不能因为接口都为 C 型或具有电子标记芯片就作为显示线。高速线的画面能力也有限定：需要主机支持视频输出，显示端具备对应输入，线材只能承载兼容链路。仅供电接口不会因换线产生画面，连接失败时应先判断是哪端不支持，而不是反复更换电源。比较视频时只引用规格已有的上限，不保证所有主机、显示器和转接路径都获得同样结果，更不能凭屏幕黑屏就认定线材损坏。

## 长度与重量影响桌面安排而非等级排序

联枢 C2 双 C 口数据线（lianshu-c2）的尺寸为“长度 2 米”；重量为“62 克”。联枢 C3 高速数据线（lianshu-c3）的尺寸为“长度 0.8 米”；重量为“48 克”。较长线可用于桌面较远的连接，但走线需预留弯曲余量，避免桌角拉扯插头根部；短线需把设备摆近，不能为接远处屏幕而绷紧。两款重量都只指线材，不含电源和设备。若主要任务是远距离补电，长度可能优先；若需要兼容视频与高速数据，则先看完整链路是否支持，再确定距离能否接受。选择应按任务作取舍，不把后缀数字当成所有维度的升级保证。
