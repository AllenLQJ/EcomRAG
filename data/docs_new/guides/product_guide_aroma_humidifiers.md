# 香薰加湿选购：先分清纯水与扩香用途

纯水加湿与水溶性香薰扩香是不同用途，不能只根据都有喷雾来互换。选择时还要核对输入电源、接口和包装内适配器。

## 是否需要香气先决定功能类型

沐息 H1 桌面加湿器（muxi-h1）的功能类型为“纯水超声波加湿，不支持香薰”；水箱容量为“250 毫升”。沐息 A1 香薰扩香器（muxi-a1）的功能类型为“超声波扩香，可用水溶性香薰液”；水箱容量为“150 毫升”。只希望桌面纯水出雾时，应按纯水加湿款选择，不加入香薰液或精油。需要水溶性香薰时再考虑扩香器，并按说明使用适配的液体，不加入油性精油。功能差异不能靠更换水箱内容跨越，包装没有香薰液也不能从展示用途推断附送。香气感受随通风和用量变化，不承诺助眠或治疗效果。

选购前可先问自己希望获得的是清水喷雾还是香气，再检查日常是否方便断电加水。功能目标明确后才能比较水箱，不能因为都有雾就要求设备用改变液体的方式承担另一种用途。

## 水箱大小与喷雾范围分别看

沐息 H1 桌面加湿器（muxi-h1）的喷雾量为“25–35 毫升每小时”；额定功率为“3 瓦”。沐息 H2 桌面加湿器（muxi-h2）的水箱容量为“600 毫升”；喷雾量为“40–60 毫升每小时”。水箱较大可减少加水频次，但喷雾量仍是室温连续模式的测试范围，不能直接换算固定运行时长。较大水箱也不是整个房间覆盖面积的证明。对桌面使用，应同时考虑是否方便断电加水、机身是否能平稳摆放以及水质影响，而不是只比较容量。缺少房间条件时，不应承诺相同的增湿幅度或把加湿等同空气净化。

## 供电接口不同不能混接

沐息 H2 桌面加湿器（muxi-h2）的输入要求为“5 伏直流、2 安”；供电接口为“通用 C 型接口”。沐息 A1 香薰扩香器（muxi-a1）的输入要求为“12 伏直流、1 安”；供电接口为“圆孔直流接口”。纯水款需另备符合输入规格的适配器，扩香款随盒提供匹配适配器，不能仅凭接口能插入就使用其他电源。圆孔直流与通用接口需要分别核对，供电线也不是储电能力。加水和移动之前应先断开连接，再按水位线操作，避免只因机身摆得下就忽略电源与取水路径。电气要求以对应型号为准，不借用相近产品参数。

若摆放位置尚未确定，应先落实平稳台面和匹配电源，再讨论水箱大小。不能用较大水箱替代对加水路径与供电条件的检查，也不把单次装水较多理解为无需管理的自动设备。

## 桌面管理与操作能力一并确认

沐息 H1 桌面加湿器（muxi-h1）的电池与联网为“无电池，不支持联网控制”；整机重量为“220 克”。沐息 H2 桌面加湿器（muxi-h2）的整机重量为“410 克”。沐息 A1 香薰扩香器（muxi-a1）的喷雾量为“15–25 毫升每小时”。这些设备均需持续外接电源，不能充满后脱线使用，也不支持联网控制。机身重量不包含加水后的总重，摆放时需要考虑实际使用状态。喷雾量并非消毒能力，商品资料没有相应健康效果保证。若目标是临时移动或远程开关，应先核对这类需求是否与规格冲突，避免购买后再把缺少的功能认作故障。
