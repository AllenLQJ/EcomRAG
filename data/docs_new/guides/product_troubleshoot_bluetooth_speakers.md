# 蓝牙音箱排障：连接无声、输入与播放时间

音箱无声不一定是同一种故障，应先判断当前音源和输入路径。排查仅限基础外部操作，接口潮湿或机身明显异常时先停用。

## 已连接却没有声音先描述两端状态

鸣澜 A1 蓝牙音箱（minglan-a1）的连接方式为“蓝牙 5.3”；额定功率为“6 瓦”。床边款既要核对播放设备端音量，也要检查机身音量旋钮，不能仅凭旋钮转过就认为声音一定输出。请区分无线列表没有找到、连接后无声、音量变化无效等现象，按说明核对当前操作。商品表没有通用重置时长，不应自行发明按键组合。可记录所播音源、连接界面和调节后的表现，便于客服判断是连接状态、音源设置还是功能异常。

## 有线无声时区分音频与充电接口

鸣澜 D1 蓝牙音箱（minglan-d1）的连接方式为“蓝牙 5.3、3.5 毫米音频输入”；充电输入为“5 伏直流、2 安，通用 C 型接口”。鸣澜 P2 蓝牙音箱（minglan-p2）的连接方式为“蓝牙 5.3”。桌面款的音频线需要另备，插入音频线不等于已给电池补电；便携款没有相同的有线音频输入。若顾客使用的是只支持无线连接的型号，换一根音频线不能增加未声明能力。若型号支持有线，应说明音源输出、实际连接端口和无线时能否播放，避免把接口用途混淆后直接判断扬声器损坏。

## 续航缩短要先看测试条件有没有改变

鸣澜 R1 蓝牙音箱（minglan-r1）的音乐续航为“18 小时”；防护等级为“IPX5”。表中播放时间是在室温、约一半音量连续本地音乐下测得，大音量或其他使用条件不能直接按同一结果判定。记录每次补电情况与音量习惯，比只比较电池容量更适合排查。防护等级也不意味着可浸泡，雨后或接口潮湿时应先保持干燥再考虑充电。若出现异常发热或明显损伤，停止复现并保存外观材料，不把持续工作作为检测前提。

## 客服核查时把输入路径一起提交

材料应包含型号、连接方式、故障发生时的音源状态和机身表现；有线与无线结果可分别描述，不自行拆开外壳。订单详情页“申请售后”，保留申请编号，在同一入口查看进度；聊天咨询不等于已提交申请。耳机、台灯、蓝牙音箱、充电设备、数据线与配件、键盘鼠标、带电的香薰加湿设备：自签收起12个月有限保修，针对正常使用下确认的非人为功能故障。有限保修以正常使用下确认的非人为功能故障为条件，保修通过检测、维修或更换处理，不能理解为整个保障期都能退货。若符合早期质量退货规则，签收之日起7天内商品存在质量问题可申请退货，运费由店铺承担。需要寄修时，由客服在售后入口给出寄修指引和地址，不自行寄往陌生地址，不使用到付。连接排查不能提前承诺换货或退款结果，未复现的现象也应如实记录，由客服结合资料判断后续方案。
