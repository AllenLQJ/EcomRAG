# 蓝牙音箱保养：接口干燥与固定摆放

音箱维护重点是防护对象、接口干燥和线材受力。未标注防护等级的机型应远离溢水与蒸汽，不能用流水清洗机身。

## 有防护等级也不能带湿充电

鸣澜 P1 蓝牙音箱（minglan-p1）的防护等级为“IPX4”；充电输入为“5 伏直流、2 安，通用 C 型接口”。鸣澜 R1 蓝牙音箱（minglan-r1）的防护等级为“IPX5”。日常防溅不等于可浸泡或长期露天放置，接口潮湿时禁止充电。露台或出游后先检查接口状态，不通过接电观察是否还能工作来判断有无进水。机身与插口都应按商品使用限制保持干燥，资料没有提供整机水洗流程，也没有清洁液配比。若有明显损伤，应保存外观并联系售后，不自行拆开外壳处理电池或扬声部件。

## 桌面款先安排水杯和线材的位置

鸣澜 D1 蓝牙音箱（minglan-d1）的防护等级为“无防水等级”；整机重量为“650 克”。鸣澜 D2 蓝牙音箱（minglan-d2）的整机重量为“980 克”。固定桌面和客厅机型未标注防护等级，应远离易溢洒的水杯与潮湿台面。移动前拔掉音频和供电连接，避免线缆拖拽；不能让机身悬在桌沿或靠插头承受拉力。额定功率较大不表示外壳更耐水，体积也不能代替稳定支撑检查。维护时保留原有线材用途，不把音频口当供电口，也不因电池可续航就忽略充电接口的状态。

## 便携附件与补电安排按资料执行

鸣澜 P2 蓝牙音箱（minglan-p2）的整机重量为“310 克”；音乐续航为“14 小时”。鸣澜 A1 蓝牙音箱（minglan-a1）的充电输入为“5 伏直流、2 安，通用 C 型接口”。出游款挂绳不作为承重工具，携带时按实际机身与其他行李安排，不能悬吊重物。音乐续航按约一半音量、室温连续本地音乐测试，保养不能保证大音量仍达到同样时长。补电前核对供电规格，资料没有统一定期充放电周期，不自行追加。带电商品乘机时，带电商品（充电宝、耳机等）乘机携带规定以航司和机场最新要求为准，客服不承诺。客服的产品维护建议不等同于对任何航班的携带许可。
