# 灵码全额与部分退款的返券核对案例

本文围绕退款范围、完成节点和原券条件说明返券判断。退现金与返优惠券应分别核查，退款获批不表示券已退回或有效期已经延长。

## 先分辨退款覆盖的是整单还是部分

已支付订单全额退款与部分退款适用不同的返券判断。全额退款后，需要继续看原券是否未过期且支持返还；部分退款不自动返还整张券。顾客查询时应说明原订单编号和退款覆盖范围，不能只说已经退货，就省略仍保留商品的情况。例如同笔购买仅退回其中商品，应按部分退款口径理解，而不能因为退回商品本身全部退款，就直接认定整笔订单属于全额退款。案例不设定具体商品价格，也不承诺只要退款数额接近原实付就自动符合整单返券条件。

## 全额退款获批与完成仍有区别

符合条件的券一般在退款完成后1个工作日内退回，起点不是申请提交、客服同意或包裹寄出。已支付订单全额退款后，未过期且支持返还是需要同时核对的条件，不能只看其中某项。顾客可先查退款是否完成，再查对应券记录；若仍处于退款处理中，应先确认资金节点，而不是把尚未出现返券认定为系统遗漏。本文不把通常处理口径写成无条件保证，也不承诺提交查询就会立即补券。核对时保留原订单与原券之间的对应关系，避免查错其他券的记录。

## 部分退款不能重复取得整张券权益

部分退款不自动返还整张券。顾客保留了订单中的其他商品时，不能因为某件商品已退款，就把原来用于整笔交易的店铺券视为已可重新使用。事实表没有列出部分退款后拆分返券或人工补券的通用方案，本文不编造这种安排，也不以未自动返还推导出客服一定会另发替代券。部分商品的现金退款按订单实际支付明细计算，优惠券抵扣部分不按现金退回。查询时应分别说明退的是哪些商品、退款状态如何和原券记录，不用券面金额直接倒推应退现金。

## 原券过期不会因退款自动延期

全额退款的返还条件包含原券未过期且支持返还，过期券不自动延期。若顾客等待退款期间看到原券日期已变化到失效状态，应核对原有效期与退款完成情况，不把退款申请日视为保留券有效期的承诺。本文不规定延期天数、替代券额度或重新领取资格，也不承诺因处理过程经历时间变化就必然补发。返券记录与原券有效期是不同信息，应一起查看；只发现券包没有可用券，尚不足以判断应按什么方式处理，需回到原券和订单的具体条件核查。

## 返券以后再购买仍要重新判断能否用

券是否已返还与新订单是否满足使用条件并非同个问题。返券后再次购买，门槛仍按适用商品优惠前金额判断，运费不参与凑券门槛；同一订单最多使用一张店铺优惠券，多张店铺券不能叠加。优惠券不是现金、储值余额或支付凭证，不能兑换现金，所以返券也不意味着资金账户增加了同等现金。顾客应查看本次结算中的实际可选结果，不承诺返还的券适用于所有新商品。若记录有疑问，可沿原订单说明退款与返券情况，不以额外付款换取所谓的返券处理。
