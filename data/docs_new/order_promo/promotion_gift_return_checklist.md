# 灵码赠品核对与退货前的赠品询问清单

本文说明怎样辨认随单赠品，以及退货时哪些赠品事项需要核实。事实表没有统一的赠品退回和折价细则，不能将案例写成额外扣款或补发承诺。

## 赠品首先应能对应订单明细

赠品在订单明细展示，未列示的赠品不自动补发。顾客查询是否随单附赠时，先找实际订单中的赠品项目，不以宣传画面中的陈设、其他顾客收到的物品或历史购买经验替代本单记录。若页面印象与明细不同，可以保留相关画面说明疑问，但不能据此直接认定仓库漏发。本文不写具体赠品名称、数量或价值，避免把不存在于事实表的活动内容变成承诺。赠品属于需要核对的订单项目，是否列示是判断依据，不因顾客期待随单获得某件物品就自动增加补发义务。

## 明细列出却未找到时先核对分包

订单可能分成多个包裹，每个包裹单独查看物流。若赠品在明细中列示而当前包裹未找到，应先核对其他包裹和装箱清单，再说明实际收到的内容。少件核查可拍摄包裹全貌、面单，保留连续开箱视频、外箱和填充物，使已收到物品与订单能够对应；不要在尚未核对分包时直接认定赠品永久缺失。是否列示与是否已送到属于不同问题，本文不承诺所有赠品与主商品同箱或同时到达。材料有助于说明情况，但不能替代针对实际包裹的核查结论。

## 申请退货时主动说明赠品现状

签收之日起7天内商品存在质量问题可申请退货，运费由店铺承担，正式申请应在订单详情页“申请售后”提交并保留申请编号。若原订单带有赠品，可在申请中同时说明赠品是否已收到、目前是否仍保留，以及准备退回哪些商品，便于核对寄回内容。事实表并未列出赠品必须随主商品退回的通用条件，说明赠品现状不等于新增审核条件。顾客也不要因为不清楚赠品处理就只在聊天咨询，而遗漏正式申请；质量问题与赠品疑问可分别写清，等待核对。

## 寄回前确认清单而非自行估价

退货审核通过后，按客服提供的国内退货指引寄回，包裹内附申请编号，不放银行卡或证件原件。涉及赠品时，可在寄件前询问指引中的寄回清单是否包含该赠品，并说明缺失或无法对应的情况。事实表未规定赠品未退回时的统一扣款标准、折价方法或替代处理，本文不承诺一定扣款，也不承诺任何情况下都可保留赠品。顾客不应自行用假定赠品价值减少应退商品或估算退款；需要确认的事项应围绕订单与批准的寄回指引核实，不凭案例新增价格。

## 把退款金额与赠品疑问分别记录

退款按订单实际支付明细计算，优惠券抵扣部分不按现金退回。赠品在订单中列示，不等于可以脱离实际支付明细推导出额外现金退款；反之，也不能仅凭有赠品就自行设定主商品退款扣减。顾客可保留订单赠品项目、售后申请与寄回清单，若客服说明中存在不清楚的处理内容，应在寄件前提出具体问题。本文只说明已知规则和待核实边界，不承诺赠品补偿、固定折价或新的返还权益。实际处理应与原交易核对，不能用赠品问题替代商品质量情况的审核。
