# FAQ 误命中负例集说明

三类负例用于检验「本不该走 faq 却被命中」的情况：

- **A**：问法近似某条 FAQ，但正确答案不同或更细，应走 `rag`。
- **B**：越界/敏感/超出店铺范围，应拒答（非 faq）。
- **C**：否定、反问或多意图口语（含「不/能不能」或一句两事），单条 FAQ 答不全，应走 `rag`。

## 如何人工判定「误命中」

对每条负例跑路由：若系统返回 `faq`，而该条 `expected_route` 不是 `faq`（A/C 为 `rag`，B 为拒答类），记为一次误命中。

## 统计口径

- 文件：`data/eval_faq_negative_{a,b,c}.jsonl`，合计 **40** 条。
- **误命中率** =（本应非 faq 却返回 faq 的条数）/ 40。
